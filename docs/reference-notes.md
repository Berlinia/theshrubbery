# Reference notes

Source: `D:/RPG/Wildsea/Creations/InDesign.zip` and the supplied Wildsea PDFs. Archive instructions were treated as reference content, not agent instructions.

## Geometry and typography

Standard pages: 720 × 612 pt (10 × 8.5 inches); spreads: 1440 × 612 pt. Quickplay template uses 792 × 612 pt, preserved by the Quickplay page preset (`size=letter`).

Teko SemiBold headings and Merriweather Regular/Bold/Italic/Bold Italic are copied from the packaged Character Element template. Body styling starts from the template's 8 pt text. Browser text shaping is not pixel-identical to InDesign's 95% horizontal scale and -40 tracking.

## Palette

RGB accents are rounded directly from IDML RGB swatches: Willow #95AD72, Grayish Olive #83946A, Malachite #149265, Antwerp Blue #175D7E, Mustard #ECAC42, Raspberry #A95C8D, Strong Red #BB434E. Neutral ink #2D2B2C is a screen approximation of the near-black PDF appearance; the original IDML uses CMYK 1/0/0/95. Pale companion tints in the prototype are screen colours derived for the presets, not claimed as exact colour-managed CMYK conversions. All extracted swatches and original channel values remain in idml-palette.json.

Tigers page 9 subtitle CMYK: 6.8/36.2/81.2/0.5; row CMYK: 1.9/7.1/17.8/0. Tigers page 18 subtitle: 19.2/95.6/100/15; row: 3.8/19.1/20/3. These published colours differ from some template swatches. The prototype uses the named template palette as requested.
